# Office Worker City (3단계: 지브리풍 광장 · 채팅 · 이모티콘 · 시간대 · 자유 주행 · 반려동물 산책)

닉네임을 정하고 들어가면, 같은 시간에 접속한 사람들이 서로 걸어 다니는 모습이 보이는 온라인 광장입니다.
고층 빌딩, 분수 광장, 카페, 편의점, 푸드트럭, 버스 정류장, 벤치, 가로등이 있는 노을 지는 퇴근길 광장입니다. (배경 코드는 `public/city.js`)

## 내 컴퓨터에서 먼저 해보기 (선택)
1. Node.js(18 이상)를 설치합니다. https://nodejs.org
2. 이 폴더에서 터미널을 열고 아래 두 줄을 실행합니다.
   - `npm install`
   - `npm start`
3. 브라우저 두 개 창에서 http://localhost:3000 을 열고 각각 다른 이름으로 입장하면 서로 보입니다.

## 무료로 인터넷에 올리기 (Render 기준)
1. GitHub 계정을 만들고 새 저장소(repository)를 만든 뒤, 이 폴더의 파일을 올립니다.
   (node_modules 폴더는 올리지 않아도 됩니다.)
2. https://render.com 에 GitHub 계정으로 가입합니다.
3. Dashboard → New → Web Service → 방금 만든 저장소를 선택합니다.
   - Runtime: Node
   - Build Command: `npm install`
   - Start Command: `npm start`
   - Instance Type: Free
   (이 폴더의 render.yaml이 같은 설정을 담고 있어서, Blueprint로 한 번에 만들 수도 있습니다.)
4. 배포가 끝나면 `https://서비스이름.onrender.com` 주소가 생깁니다. 이 주소를 친구들에게 보내면 됩니다.

## 무료 서버의 제약 (꼭 알아두세요)
- 15분 동안 아무 접속이 없으면 서버가 잠듭니다. 다음 첫 접속은 약 1분 걸릴 수 있습니다.
  접속 화면에 "서버를 깨우는 중" 안내가 뜨고 자동으로 재시도합니다.
- 서버가 재시작되면 접속이 끊깁니다. 화면이 자동으로 다시 연결을 시도합니다.
- 기록은 저장되지 않습니다(접속 중인 사람들만 서로 보임).
- 상시 운영(잠들지 않음)이나 정식 도메인이 필요해지면 유료 플랜이 필요합니다.
  무료 플랜에서 내 도메인(예: lounge.내도메인.com)을 연결할 수 있는지는 가입 후 Render 설정 화면에서 확인하세요.

## 설정 값 (환경 변수, 선택)
- `PORT` 호스팅이 자동으로 넣어줍니다.
- `MAX_PLAYERS` 방 하나의 최대 인원 (기본 40)

## 서버가 막아주는 것
- 위치 조작: 사람이 낼 수 있는 속도 이상으로 움직이면 서버가 되돌립니다.
- 광장 밖 이탈, 비정상적으로 큰/잦은 메시지, 이름에 들어간 특수문자.
- 아직 없는 것: 채팅 욕설 필터, 신고, 로그인 → 5단계(상용 준비)에서 추가합니다.


## 조작
- WASD 이동, Shift 달리기, Space 점프, C 앉기, Z 눕기, E 상호작용(벤치/나무/자동차), V 시야각(좁게/기본/광각)
- Enter 채팅(60자), 숫자 1~8 이모티콘
- 하루는 현실 36분이고 서버 시간 기준이라 모두 같은 시간대를 봅니다. 테스트: 주소 뒤에 `?t=18` 처럼 붙이면 그 시각으로 고정됩니다.

## 새로 생긴 것
- 자동차: 광장 곳곳에 8대가 주차되어 있어요. E로 타면 직접 운전합니다(WASD, Space 핸드브레이크, Shift 부스트). H 경적, L 라이트, R 라디오, 오른쪽 메뉴에서 색상 변경. 도로 밖 어디든 달릴 수 있어요.
- 강아지 6마리, 고양이 6마리: E 쓰다듬기, G 간식, 강아지는 F로 산책(리드줄). 산책하면 가끔 똥을 싸요 → E로 줍고 쓰레기통(초록색)에서 E로 버리면 🧹 점수가 올라가요.

## 채팅 규칙
- 거친 말은 서버에서 칭찬하는 말로 자동으로 바꿔서 내보내요(`server/filter.js`). 닉네임에도 같은 규칙이 적용돼요.
- 바꿀 말을 더하거나 빼려면 `server/filter.js`의 `BAD` 목록을, 바뀌어 나갈 말은 `PRAISE` 목록을 고치면 돼요.
