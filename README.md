# Healing Lounge

닉네임을 정하고 들어가면, 같은 시간에 접속한 사람들이 서로 걸어 다니는 온라인 힐링 라운지예요.
가운데 "힐링 광장"에서 시작하고, 광장의 달문(둥근 돌문)으로 들어가면 힐링 공간 4곳으로 갈 수 있어요.

## 힐링 공간
- 🌲 숲속 쉼터: 햇살 기둥, 연못, 통나무 의자, 오를 수 있는 큰 나무, 나비
- 🌅 노을 바닷가: 파도, 부두(끝 벤치에서 노을 보기), 모닥불과 통나무 의자, 파라솔
- 🌌 별빛 언덕: 별똥별과 은하수, 돗자리에 누워 별 보기, 망원경, 전구줄
- ♨️ 달빛 온천: 따뜻한 물에 들어가 앉기, 등불, 정자, 벚꽃잎, 하늘로 오르는 소원 등
공간마다 사람이 따로 모여요(그 공간에 있는 사람끼리만 보이고 채팅이 전달돼요). 돌아올 때는 공간 안의 "광장으로" 문에서 E.

## 손님과 회원
- 손님: 가입 없이 바로 입장해서 광장·힐링 공간·채팅·동물을 똑같이 즐겨요. 별과 출석은 없어요.
- 회원(아이디+비밀번호): 별 ✨, 출석 도장, 미션 보상, 꾸미기가 계정에 저장돼서 다른 기기에서도 이어져요. 이메일은 받지 않아서 비밀번호를 잊으면 되찾을 수 없어요(탈퇴는 로그인 화면에서 가능).
- 한 계정은 한 곳에서만 접속돼요. 다른 곳에서 로그인하면 먼저 접속한 쪽이 끊겨요.
- 비밀번호는 scrypt로 암호화해서 저장해요. 별·출석·구매·미션 진행은 모두 서버가 계산하고 확인해서, 화면 값을 고쳐도 소용없어요.

## 매일 접속하고 싶게 만드는 것 (회원, 🎁 버튼 또는 K)
- 출석 도장: 7일 도장판, 도장마다 ✨ 보상, 연속 3/7/14/30일 보너스, 7번째 도장은 꾸미기 선물. 하루 쉬어도 연속 기록이 이어져요.
- 오늘의 한마디, 오늘의 미션 4개(매일 자정 한국 시간) + 오늘의 추천 공간(광장 문 위 ✨). 모두 끝내면 보너스.
- 꾸미기: ✨ 로 고양이 귀, 별 머리핀, 토끼 귀, 꽃 화관, 천사 링, 작은 날개, 버섯 모자를 사서 입어요. 다른 사람에게도 보여요.

## 조작
- WASD 이동, Shift 달리기, Space 점프, C 앉기, Z 눕기, E 상호작용(문/벤치/나무/자동차/동물), V 시야각, K 오늘의 힐링
- Enter 채팅(60자), 숫자 1~8 이모티콘
- 광장의 하루는 현실 36분이고 서버 시간 기준이라 모두 같은 시간대를 봐요. 힐링 공간은 시간이 고정(숲 아침, 바다 노을, 별빛 밤, 온천 초저녁)이에요. 테스트: 주소 뒤에 `?t=18` 처럼 붙이면 광장 시각이 고정돼요.
- 광장: 자동차 8대(E로 타서 직접 운전, H 경적, L 라이트, R 라디오), 강아지·고양이 12마리(E 쓰다듬기, G 간식, 강아지는 F로 산책, 똥은 E로 줍고 쓰레기통에 버리기)

## 파일 구조
- `server/index.js` 서버(접속, 방 나누기, 이동 검증, 문 통과, 동물, 기록 전달), `server/filter.js` 욕설→칭찬 변환
- `server/auth.js` 가입·로그인·탈퇴, `server/db.js` 계정 저장소, `server/account.js` 별·출석·미션 계산
- `public/index.html` 화면과 조작, `public/daily.js` 보상·가격·미션 규칙(서버와 공유)
- `public/city.js` 광장 배경, `public/spaces.js` 힐링 공간 4곳과 달문, `public/zones.js` 공간 이름·크기·문 위치
- 새 힐링 공간을 늘리려면 `zones.js`에 한 줄을 더하고 `spaces.js`에 장면을 하나 만들면 돼요.

## 내 컴퓨터에서 먼저 해보기 (선택)
1. Node.js(18 이상)를 설치합니다. https://nodejs.org
2. 이 폴더에서 `npm install` 후 `npm start`
3. 브라우저 두 개 창에서 http://localhost:3000 을 열고 각각 다른 이름으로 입장하면 서로 보입니다.

## 무료로 인터넷에 올리기 (Render 기준)
1. GitHub 저장소에 이 폴더의 파일을 올립니다(node_modules 제외).
2. Render → New → Web Service → 저장소 선택. Build `npm install`, Start `npm start`, Free.
3. 배포가 끝나면 `https://서비스이름.onrender.com` 주소가 생겨요.
- 저장소나 Render 서비스 이름이 예전 이름(office-worker-city)이어도 동작에는 아무 문제가 없어요. 바꾸고 싶으면 GitHub Settings와 Render Settings에서 각각 Rename 하면 돼요.

## 계정 저장소 연결하기 (꼭 필요해요)
Render 무료 서버는 재시작·재배포 때마다 파일이 지워져서, 아무 설정이 없으면 **가입한 계정이 사라져요**. 무료 데이터베이스를 하나 연결해 주세요.
1. https://neon.tech 에서 가입 → Create project (무료, 기간 제한 없음, 지역은 가까운 곳)
2. 프로젝트 화면의 Connection string(`postgresql://...` 로 시작)을 복사
3. Render → 내 서비스 → Environment → Add Environment Variable
   - Key `DATABASE_URL`, Value 복사한 주소 → Save (자동으로 다시 배포돼요)
4. 서버 로그에 "계정 저장소: Postgres" 가 보이면 성공. 표는 서버가 알아서 만들어요.
- (선택) `AUTH_SECRET`에 아무 긴 문자열을 넣으면 로그인 유지 서명 키를 직접 정할 수 있어요. 안 넣으면 DATABASE_URL로부터 자동으로 정해져요.
- 내 컴퓨터 테스트에서는 DATABASE_URL 없이 `data/db.json` 파일에 저장돼요.

## 무료 서버의 제약
- 15분 동안 접속이 없으면 서버가 잠들어요(다음 첫 접속은 약 1분). 화면이 자동으로 재시도해요.
- 서버가 재시작되면 접속이 끊겨요(자동 재연결). 계정과 기록은 데이터베이스에 남아요.

## 설정 값 (환경 변수, 선택)
- `PORT` 호스팅이 자동으로 넣어줘요. `MAX_PLAYERS` 방 하나의 최대 인원(기본 40, 광장과 공간 4곳이 각각 따로 계산)
- `DATABASE_URL` 계정 저장소(위 안내), `AUTH_SECRET` 로그인 서명 키(선택)

## 서버가 막아주는 것
- 위치 조작(속도 제한), 공간 밖 이탈, 문에서 멀리 떨어진 곳에서의 이동 요청, 비정상적으로 크거나 잦은 메시지, 이름의 특수문자
- 로그인 시도 횟수 제한(아이디·IP별), 가입 횟수 제한, 별·구매·미션 보상 서버 검증
- 거친 말은 칭찬하는 말로 자동 변환(`server/filter.js`). 닉네임과 아이디에도 적용돼요.
- 아직 없는 것: 신고, 비밀번호 찾기(이메일 연동), 개인정보 처리방침 화면 → 5단계(상용 준비)에서 추가합니다.
